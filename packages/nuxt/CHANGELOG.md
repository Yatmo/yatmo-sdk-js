# Changelog

## 1.0.0

First release: module options and runtime config (frontend key, backend key, country, language, also from
`NUXT_PUBLIC_YATMO_KEY` and `NUXT_YATMO_KEY`), auto-imported `YatmoMap`, `YatmoInteractiveMap`, `YatmoPois`
and `YatmoNeighbourhoodText` with the config filled in, composables `useYatmo`, `useYatmoNeighbourhoodText`
and `useYatmoSummary` fetching on the server for an indexable text. Nuxt 3.10 and 4.
