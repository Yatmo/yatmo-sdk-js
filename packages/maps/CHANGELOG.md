# Changelog

## 1.0.1

`createIframe` takes a digits-only height as pixels; `MapConfigKnown` type (the typed options without the
catch-all index signature) for consumers that extend it.

## 1.0.0

First release: typed `iframeUrl`, `createIframe` and `mountIframe` for the iframe plugin; `mountMap`, `mountSummary`
and `mountSummaryText` loaders for the JavaScript map, summary table and neighbourhood text plugins.
