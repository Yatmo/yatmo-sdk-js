# Changelog

## 1.0.0

First release: `YatmoMap` (the iframe plugin, server-renderable), `YatmoInteractiveMap` (the JavaScript map plugin),
`YatmoNeighbourhoodText` and `YatmoPois` (from server data or fetched in the browser, with `fallback`, `error` and
`place` slots), `useYatmoClient`, `useYatmoText` and `useYatmoSummary` composables. Vue 3.3 and later, Nuxt 3.
