# Changelog

## 1.0.0

First release: the `yatmo()` integration (loads the Yatmo web components once per page, declares the key,
country and language), the `YatmoMap`, `YatmoPois` and `YatmoText` components (client-rendered elements) and
`YatmoNeighbourhoodText`, rendered at build time or on the server with the backend key, so the neighbourhood
text is part of the HTML search engines index.
